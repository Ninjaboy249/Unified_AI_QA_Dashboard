# Five-Minute Demo Script

## 00:00 Orient

Open the Command Center. Show the module map, operational metrics, recent activity, and the natural-language intent bar.

## 00:40 Generate

Go to Test Case Generator. Create two Android sign-in test cases. Point out typed fields, exact count validation, editable output, copy and export.

## 01:50 Draft

Go to Bug Drafter. Turn a crash summary into a structured defect draft. Emphasize reproduction steps, expected versus actual behavior, tags, and human approval.

## 03:00 Ground

Go to Policy Assistant. Ask a Teams external access question. Show the source title, file name, confidence, and refusal behavior for unsupported questions.

## 04:05 Prove

Open Health & Evidence. Show health mode, configured GPT-5 mini model, route count, API route count, local knowledge, and validation controls.

## 04:40 Close

Close with impact metrics, limitations, and the next release plan.
